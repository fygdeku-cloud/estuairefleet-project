# Design system INSAM

La palette utilise le rouge INSAM `#C8102E`, le rouge vif des signaux `#E4002B`, le blanc, l’encre `#1A1A1A` et des fonds gris très légers. Les tokens et composants sont dans `estuairefleet/static/css/design-system.css`.

Les écrans privilégient une action principale, des zones tactiles de 48 pixels, un contraste lisible et des états vides explicites. Le bouton de signal mesure au moins 176 pixels sur mobile et reste le point le plus visible de l’écran. Tailwind CSS et Flowbite structurent les interfaces, tandis que Leaflet est servi depuis `static/vendor`.
